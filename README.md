# pg-alembic

PostgreSQL with Alembic preinstalled.

| Image                                | Base                |
| ------------------------------------ | ------------------- |
| `ghcr.io/clemensio/pg-alembic:16`    | `postgres:16-alpine` |
| `ghcr.io/clemensio/pg-alembic:17`    | `postgres:17-alpine` |
| `ghcr.io/clemensio/pg-alembic:18`    | `postgres:18-alpine` |

Added on top of the base image: `alembic`, `psycopg2`.

Platforms: `linux/amd64`, `linux/arm64`.
